# Ranch
Code: `js/engine/ranch.js`, `ranchApi.js`, `animals.js`, `carpet.js`, `js/ui/ranch.js`, `ranchView.js`, `loom.js`, `config/ranch.json`.

- [ ] Opens with resources only. Only one world runs: the farm waits while the ranch is open, and back again.
- [ ] Each area has its own drone and code tab; the big ▶ runs all; ⏹ stops all.
- [ ] Animals: hunger, thirst, dirt, mood; products only when happy; nothing dies. `rescue()` gives feed once a day when stuck.
- [ ] Commands: `vercnel`, `lcnel`, `datarkel`, `kitel`, `vacharel`, `gnel`, `berel`, `tanel`, `grel`/`kardal`, `erb()` (handlers run only when the drone is free), `buzhel`, `norogel`, `kapel`, `xuzel`, `zangel`, `eshovBerel`/`eshovTanel`, `tonavachar`.
- [ ] Daily prices are the same for everyone and change at midnight. The shop: every item, `needs`, levels.
- [ ] Loom: `gorg()`, `hyusel(x, y, guyn)`, 9×9, no knot changed, order pay by likeness.
- [ ] Fair ending, then New Game Plus keeps code and Perfection.
- [ ] Ranch buttons sit at the bottom right and work on the first click while programs run. All 3 sizes.
